# Dataset License and Attribution

## Dataset

- **Name:** Online Retail
- **Creator:** Daqing Chen
- **Repository:** UCI Machine Learning Repository
- **UCI dataset ID:** 352
- **DOI:** https://doi.org/10.24432/C5BW33
- **Versioned file in this repository:** `data/raw/Online Retail.xlsx`

UCI describes the dataset as 541,909 transactions recorded between 1 December
2010 and 9 December 2011 for a UK-based registered non-store online retailer.

## Citation

Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C5BW33
